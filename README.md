# 🎬 YouTube Thumbnail Saver

A sleek, ultra-fast, and responsive web application to view and download HD & 4K YouTube video thumbnails instantly. Built with a modern dark glassmorphism UI.

![YouTube Thumbnail Saver Preview](https://img.shields.io/badge/Status-Active-brightgreen) ![License-MIT](https://img.shields.io/badge/License-MIT-blue)

---

## ✨ Features

- ⚡ **Instant Extraction:** Automatically parses YouTube video URLs and Shorts links.
- 🖼️ **Multiple Resolutions:** Download thumbnails in HD (1080p), High Quality (480p), Medium (360p), or Standard quality.
- 🎨 **Glassmorphism Dark Theme:** Modern UI designed with responsive CSS and clean layout.
- 🕒 **Search History:** Remembers your recently searched thumbnails using local storage.
- 📋 **One-Click Copy:** Copy thumbnail URLs directly to your clipboard.
- 📱 **Fully Responsive:** Looks and works great on mobile, tablet, and desktop browsers.

---

## 🛠️ Built With

- **HTML5** - Structure and layout
- **CSS3** - Glassmorphism, animations, and responsive flexbox/grid layout
- **JavaScript (Vanilla)** - URL regex parsing, local storage handling, and dynamic preview generation

---

## 🚀 Quick Start / How to Use

1. Copy any YouTube video link or Shorts URL (e.g., `https://www.youtube.com/watch?v=dQw4w9WgXcQ`).
2. Paste the URL into the search bar.
3. Choose your desired resolution preview.
4. Click **Download** or **Copy Link**!
